# Fontes e licenças — Desktop radial

`LGPL-3.0-only.txt` é o texto da licença Qt qtbase v6.12.0. `Python-3.12-LICENSE.txt` corresponde ao CPython 3.12.12. `Pillow-13.0.0-LICENSE.txt` e `pypdf-6.21.4-LICENSE.txt` foram copiados das versões fixadas em `requirements.txt`. `resvg_py-0.5.0-LICENSE.txt` é a licença (MIT) do pacote `resvg-py` 0.5.0, que embute o motor resvg (Rust); `pillow_heif-1.8.1-LICENSE.txt` (BSD-3-Clause, código do pacote `pillow-heif`) e `pillow_heif-1.8.1-LICENSES_bundled.txt` (bibliotecas dos wheels: libheif 1.23.6 e libde265 1.1.3, LGPL-3.0, e **x265 4.3, GPL-2.0**, com os endereços do código-fonte de cada uma; os wheels do Windows trazem ainda o runtime MinGW-w64). `resvg_py-0.5.0-SBOM.cyclonedx.json` é a lista de componentes e licenças que o próprio wheel traz (resvg 0.48.1 e dependências, todas MIT, Apache-2.0, BSD, Zlib, Unlicense ou Unicode-3.0; nenhuma copyleft).

No Windows, `pywin32` é instalado condicionalmente e usa os componentes COM/Win32 para consultar a seleção do Explorer. O script `package.py` registra versões das distribuições e copia os arquivos de licença disponíveis para o pacote. Verifique o diretório `licenses/` da build Windows antes de redistribuir. A integração não registra teclas digitadas; o único estado global consultado é Shift pressionado/não pressionado.

**OCR (0.9.22).** O reconhecimento de texto usa o **Tesseract** (Apache-2.0, copyright Google e Hewlett-Packard; texto em `licenses/Apache-2.0.txt`) como **programa externo**, chamado como processo separado (não é ligado ao aplicativo). Os dados de idioma `tessdata/por.traineddata` e `tessdata/eng.traineddata` vêm do repositório `tesseract-ocr/tessdata_fast` (commit 87416418657359cb625c412a48b6e1d6d41c29bd, de 01/08/2024; Apache-2.0, licença copiada em `tessdata/LICENSE-tessdata_fast.txt`); `tessdata/pdf.ttf` é a fonte sem glifos do Tesseract usada no PDF pesquisável (Apache-2.0, copiada do pacote Debian tesseract-ocr 5.3.4). **No Windows o pacote deve incluir a pasta `tesseract/`** (tesseract.exe e DLLs, por exemplo do instalador de UB Mannheim); cada DLL incluída (Leptonica e bibliotecas de imagem) tem a sua licença, que precisa ser conferida e copiada para `licenses/` antes de distribuir — **isso ainda não foi feito nem verificado**. No Linux o programa vem do pacote da distribuição (`tesseract-ocr`). Código-fonte do Tesseract: https://github.com/tesseract-ocr/tesseract.

Wheels (`cp312`, Windows x64 e manylinux x86-64) conferidos no PyPI; sem GPL.
